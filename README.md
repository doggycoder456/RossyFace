# RossyFace
This project aims to integrate ROS (Robot Operating System), the SO-101, and CoppeliaSim to create a unified system that monitors the robot's joints and velocity from the live robot and mirrors them in a simulation.

#RoadMap

## Phase 1: Construct Simulation of SO-101 in Coppelia
This phase involves reassembling the SO-101 into a usable model for simulation in CoppeliaSim. Next, configure this model with the correct joint parameters.
## Phase 2: Program a ROS node instance to interact with the simulation in Coppelia
This phase involves configuring the right node configuration to both monitor and deliver instructions to the simulation.
## Phase 3: Assemble and Program the Robot.
Use the provided instructions from the Hugging Face repo to assemble the robot and program the motors.
